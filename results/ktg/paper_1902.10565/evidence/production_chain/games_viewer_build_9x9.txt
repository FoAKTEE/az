== 9x9 production-chain game viewer: per-link paging ==
host    login03
date    2026-09-05T09:53:25Z
python  Python 3.9.21

A whole-chain page grows past what the host will take. Games now carry the loop
cycle they were produced in, so the run can be cut into pages per chain link or
per cycle range, and a build that would exceed the ceiling stops instead.

Cycles come from the loop log: every cycle leaves a timestamped pre-gatekeeper
marker, the worker writes one self-play file per cycle and one gatekeeper file per
cycle that had a candidate, and each file is finished after its own cycle's marker
and before the next. The mapping is checked for collisions at every build.

-------------------------------------------------------------------------------
command lines

    cd results/ktg/paper_1902.10565/codes/eval/games_viewer
    python3 build_viewer.py --preset p1 --link 1 --all-links-index   # link 1 page
    python3 build_viewer.py --preset p1 --link 1 --test              # with tests A-D
    python3 build_viewer.py --preset p1 --cycle-range 1-50           # any cycle span
    python3 build_viewer.py --preset p1                              # whole run
    python3 build_viewer.py --preset t7                              # the 7x7 run
